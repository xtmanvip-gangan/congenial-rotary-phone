# YOYO 首页「星光启程站」设计规格

## 目标

重设计主播端小程序首页。页面只承载“活动广场”“学习中心”两个核心入口与待办事项，通过一张占据首屏约一半的 YOYO 故事场景、两块异形入口瓷片和克制的待办卡片，建立大气、简约、时尚且具有品牌记忆点的首页。

本次仅重构首页视觉与入口呈现，不改变现有待办业务判定、活动与学习数据来源、页面跳转目标和只读状态逻辑。

## 核心故事

主题为「星光启程站 · 出发版」。YOYO 背着蓝粉小星包，站在透明悬浮星轨平台上，身体微微向前，准备沿星光轨道开启今天的成长旅程。远处两座漂浮目的地分别暗示活动舞台与成长学院，形成“从首页出发，去活动或学习”的完整叙事。

YOYO 必须保持既有 IP 特征：浅蓝短绒兔子、慵懒眉眼、白色腹部、蓝色鼻头和柔和腮红。表情从日常慵懒调整为轻微期待，但不能变成过度兴奋或幼儿化形象。

## 页面信息架构

页面从上到下分为三个区域：

1. 星光启程站主视觉。
2. 活动广场与学习中心两个异形入口。
3. 待办事项列表。

两个入口仍是页面唯一快捷入口。首页不增加排行榜、运营数据、轮播图、公告、签到或其他业务模块。

## 主视觉场景

- 主视觉占首屏可视高度约 `48%–52%`，宽度铺满屏幕。
- 场景以完整背景图交付，设计基准宽度为 `750rpx`；图片需预留顶部导航安全区和底部入口叠放区。
- 背景由品牌蓝 `#7EA3E0`、冰透浅蓝、白色晨光组成，少量粉色用于星光、背包和云层反射。
- 场景底部必须自然渐变至页面底色 `#F7F8FA`。
- YOYO 位于画面右侧，主体约占场景宽度的 `38%–44%`，不能遮挡左侧标题。
- 星轨从 YOYO 脚下向远处延伸，连接活动舞台与成长学院；远景只作为叙事暗示，不放可点击文字。
- 星星元素控制在少量关键节点，不使用满屏散点装饰。
- 不出现皇冠、金币、奖杯、复杂 UI 截图、品牌外文字或水印。

## 问候文案

文案位于主视觉左上安全区域，使用深色文字：

- 主标题：`和 YOYO 一起，向闪光出发`
- 副标题：`每一次行动，都在点亮你的成长轨迹`

主标题最多两行，使用展示级半粗体；副标题最多两行，降低对比度。文案保持为页面原生文字，不烘焙进背景图，以适配不同屏幕和后续修改。

## 异形入口瓷片

两块瓷片悬浮叠压在主视觉底部，整体高度约 `180–210rpx`，形成从场景进入业务内容的过渡。

### 活动广场

- 位于左侧，视觉面积略大。
- 采用冰蓝玻璃质感的弧形舱门轮廓：左下与左上保持大圆角，右上形成外扩弧面。
- 标题：`活动广场`。
- 副标题：`发现舞台 · 赢取奖励`。
- 内部使用抽象舞台光束与一颗四角星，不出现复杂插画。

### 学习中心

- 位于右侧，位置比活动瓷片高约 `12–18rpx`。
- 采用粉蓝渐变切角轮廓：左上内收、右上与右下保持柔和圆角。
- 标题：`学习中心`。
- 副标题：`点亮能力 · 解锁成长`。
- 内部使用抽象星轨阶梯或上升光点。

### 共同规范

- 两块瓷片允许约 `±2°` 的轻微视觉倾斜，但内部文字保持水平。
- 使用半透明玻璃、高光边缘和柔和阴影，不使用厚重拟物边框。
- 点击区域必须覆盖完整瓷片，最小可点击区域不低于 `88rpx`。
- 按下态缩放至 `0.98`，高光沿边缘轻微移动；动画时长 `160–220ms`。
- 活动入口跳转 `/pages/activities/index`，学习入口跳转 `/pages/training/index`。

## 待办事项

- 待办区位于入口瓷片下方，左右保持现有页面通用间距。
- 标题行显示“待办事项”和 `{todos.length} 项`。
- 列表使用白色大圆角卡片，不再增加彩色大面积背景。
- 每项包含品牌蓝星点、任务标题、可选的简短状态说明和右箭头。
- 分隔线使用低对比灰色；单行高度满足触控区域要求。
- 待办排序与点击行为沿用现有 `TodoItem` 数据，不改变业务逻辑。

空状态使用简洁星星插画或 YOYO 小尾巴元素，并显示：`今天没有待办，和 YOYO 去逛逛吧`。空状态插画不得抢过主视觉。

## 状态与异常

- 加载状态继续使用现有页面加载逻辑，不显示假的待办数据。
- 请求失败继续使用现有错误状态与重试行为。
- 只读浏览状态保留“运营确认中 · 可先浏览”提示及“查看状态”动作。
- 无待办时入口瓷片仍保持可用。
- 背景图加载失败时，主视觉保留品牌蓝到 `#F7F8FA` 的 CSS 渐变与原生标题，不出现大块空白。

## 响应式与安全区

- 设计基准为 `750rpx`，适配常见微信小程序手机宽度。
- 顶部背景延伸到自定义导航栏后方，文案从导航安全高度下方开始。
- YOYO 与两个远景目的地不得进入胶囊按钮安全区。
- 窄屏下两个入口仍保持并排，但减小重叠与倾角；不允许标题换成三行。
- 待办卡片底部预留 TabBar 与设备安全区。

## 资源边界

- 新增一张首页主视觉背景图，建议源文件至少 `1500×1100`，项目交付按实际页面比例压缩为 WebP 或高质量 JPEG。
- 如背景图包含透明延伸层，可额外交付一张 RGBA PNG；默认优先使用单张完整背景图。
- 入口图形优先用 CSS 渐变、伪元素与裁切实现，避免新增两张大位图。
- YOYO 的小星包属于本场景专用造型，不改动 IP 基础三视图。

## 验收标准

1. 首屏第一眼能看出 YOYO 正准备沿星轨出发，画面具有明确故事而非角色贴图。
2. 主视觉约占首屏一半，底部自然过渡到 `#F7F8FA`。
3. 活动广场与学习中心是两块明显不同、可点击且文字清晰的异形瓷片。
4. 页面仍只包含两个入口和待办事项，没有新增业务模块。
5. 待办的加载、空态、错误、只读和点击行为保持可用。
6. 常见微信小程序屏幕下无文字遮挡、YOYO 裁切、横向溢出或 TabBar 覆盖。
7. 微信小程序构建通过，并完成有待办、无待办和只读浏览三种页面状态的视觉检查。
