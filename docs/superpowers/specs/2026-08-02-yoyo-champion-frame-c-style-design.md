# YOYO 排行榜冠军头像框 C 款设计规格

## 目标

重做日榜、周榜、月榜的第一名头像框，使三套冠军框统一采用用户提供的参考款式，同时通过材质、色彩和光效匹配各自背景。第二名、第三名头像框及三套排行榜背景不在本次修改范围内。

## 统一造型

- 以 `miniapp-anchor/src/assets/leaderboard/avatar-frame-rank-1.png` 为造型参考。
- 保留毛绒双兔耳、厚双层圆环、三颗立体四角星和饱满的 3D 高光体积。
- 采用用户确认的 C「高光典礼」方向：轮廓与参考款一致，强化材质反射、星光与外发光。
- 不增加皇冠、文字、数字、奖牌或其他新符号。
- 三套框保持相同外轮廓和元素位置，切换榜单时只改变材质、配色与光效。

## 三套主题

### 日榜

- 主色：品牌蓝 `#7EA3E0`。
- 辅助色：冰透浅蓝、白色高光。
- 点缀色：少量柔和腮红粉。
- 材质：柔软浅蓝毛绒兔耳、半透明玻璃双环、珍珠白星星。
- 氛围：明亮、轻盈、晨光感；外发光清透，不压过日榜天空背景。

### 周榜

- 主色：深钴蓝与电光蓝。
- 辅助色：蓝紫晶体反射。
- 点缀色：少量冷紫高光。
- 材质：深蓝短绒兔耳、切面晶体双环、冰晶星星。
- 氛围：锐利、竞技、能量充足；发光强于日榜，但保持头像区域清晰。

### 月榜

- 主色：深海蓝与品牌蓝 `#7EA3E0`。
- 辅助色：粉紫极光渐变。
- 点缀色：星钻白与少量腮红粉。
- 材质：深蓝丝绒兔耳、星空玻璃双环、粉紫星钻。
- 氛围：华丽、梦幻、月度典礼；三套中仪式感最强，但不扩大外轮廓。

## 文件与几何约束

- 输出文件：
  - `miniapp-anchor/src/assets/leaderboard/themes/day/avatar-frame-rank-1.png`
  - `miniapp-anchor/src/assets/leaderboard/themes/week/avatar-frame-rank-1.png`
  - `miniapp-anchor/src/assets/leaderboard/themes/month/avatar-frame-rank-1.png`
- 每个文件均为 `1024×1024` RGBA PNG。
- 图形中心固定为 `(512, 512)`。
- 圆心半径 `r≤455px` 的头像安全区必须完全透明。
- 四角必须完全透明，无底色、无阴影底板。
- 不允许残留纯绿抠图边、文字、水印或人像。
- 现有三个冠军框先保留为同目录备份文件，再替换正式文件。

## 验收标准

1. 三个冠军框第一眼均能识别为参考图同款。
2. 双兔耳、厚双环、三颗星的结构和相对位置一致。
3. 日、周、月三套在材质与配色上有明显区分，并与各自背景协调。
4. `1024×1024`、RGBA、透明四角和 `r≤455px` 透明安全区全部通过像素级检查。
5. 将头像框按冠军位尺寸叠加到对应背景时，不遮挡头像主体，不改变头像中心。

## 交付方式

替换三套主题目录中的冠军框正式文件，同时提供日、周、月并排预览图，更新排行榜三主题素材 ZIP，并在提交前执行尺寸、透明通道、安全孔、纯绿残边和压缩包完整性检查。
